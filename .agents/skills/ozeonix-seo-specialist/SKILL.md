# Ozeonix SEO Specialist

- Review canonical URLs.
- Check indexing directives.
- Identify broken links.
- Review redirect behavior.
- Check mobile usability.

- Create meaningful meta descriptions.
- Maintain logical heading hierarchy.
- Optimize image alt text.
- Use descriptive URLs.
- Avoid keyword stuffing.

## Structured Data

- Use accurate Organization information.
- Validate structured data.

## Performance

- Optimize images.
- Minimize unnecessary scripts.
- Improve loading performance.

## Reporting

- Provide exact affected file paths.
- Explain proposed changes.
