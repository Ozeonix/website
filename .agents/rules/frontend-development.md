# Frontend Development Standards

## Before Development
- Inspect the existing project architecture.
- Identify the existing framework, dependencies and conventions.
- Review existing components before creating new ones.
- Understand the current implementation before editing.

## Development
- Follow the existing framework and architecture.
- Build reusable and maintainable components.
- Keep components focused and organized.
- Avoid unnecessary dependencies.
- Use semantic HTML.
- Maintain consistent styling.
- Avoid duplicated code.

## Responsive Design
- Support mobile, tablet, laptop and desktop.
- Test navigation and layouts at different screen sizes.
- Prevent horizontal overflow.
- Ensure buttons and forms work on touch devices.

## User Experience
- Provide clear loading and error states.
- Add meaningful hover and focus states.
- Use accessible navigation.
- Keep animations smooth and lightweight.
- Respect reduced-motion preferences.

## Performance
- Optimize images and assets.
- Minimize unnecessary JavaScript.
- Avoid unnecessary client-side rendering.
- Monitor Core Web Vitals.

## Verification
- Run relevant linting and tests.
- Check browser console errors.
- Verify responsive behavior.
- Confirm existing functionality still works.
